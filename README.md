# SmartMediIoT

Sistema Inteligente de Recordatorio de Medicamentos orientado al monitoreo y control de tratamientos médicos mediante tecnologías web modernas e integración futura con dispositivos IoT.

El sistema permite la gestión de pacientes, configuración de tratamientos médicos, monitoreo clínico, generación de reportes y automatización de recordatorios inteligentes para mejorar el cumplimiento de la medicación.

# Arquitectura del Sistema

El proyecto SmartMediIoT está desarrollado bajo una arquitectura Cliente-Servidor y una Arquitectura en Capas, permitiendo una mejor organización, mantenimiento y escalabilidad del sistema.

La arquitectura Cliente-Servidor permite que los usuarios interactúen mediante una interfaz web desde cualquier navegador, mientras que el servidor procesa la lógica del sistema, controla la información médica y administra los tratamientos de los pacientes.

Por otra parte, la Arquitectura en Capas divide el sistema en tres componentes principales:

- Capa de Presentación:
  Encargada de la interfaz visual desarrollada en HTML5 y CSS3.

- Capa Lógica:
  Desarrollada en Python utilizando el framework Flask para el procesamiento de datos y control de funcionalidades del sistema.

- Capa de Datos:
  Implementada inicialmente mediante archivos JSON para el almacenamiento de pacientes y tratamientos médicos, con posibilidad futura de migración a MySQL o Firebase Realtime Database.

El sistema fue diseñado con un enfoque moderno y adaptable, permitiendo futuras integraciones con tecnologías IoT como ESP32, monitoreo inteligente y alertas médicas en tiempo real.
